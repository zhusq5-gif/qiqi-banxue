当前只落可从教育部公开来源直接核验的建模样板：

- 标准文档：2 份（语文、英语，2022年版）。
- 样板条款：8 条。
- 知识点候选映射：6 条。
- 正式审核映射：0 条。
- 官方来源状态：`official_source_verified`。
- 知识点映射状态：`candidate_review`。

官方来源核验与知识点映射审核是两个独立状态，系统禁止用前者替代后者。

## 数据边界

当前 React 仓库中的课程数据仍是研究种子，不代表专家认证或最新版教材。任何正式发布状态必须满足教材版次、课标覆盖、教研审核、来源权利和内容问题等门禁。

课标证据层目前不是2022语文/英语课标全文数据库：语文先加入核心素养、实践领域与书写学段样板；英语先加入核心素养与跨文化培养方向。下一阶段继续扩充可稳定定位的正式条款，并进入人工审核队列。
