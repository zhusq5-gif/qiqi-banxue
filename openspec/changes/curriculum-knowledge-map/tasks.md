## 验收标准

1. `npm run build` 通过。
2. `npm test` 通过现有回归与课程种子不变量测试。
3. 登录后 `/knowledge-map` 可访问且不会修改儿童云端数据。
4. 页面明确显示“研究版”，不把未审核数据标记为正式结论。
5. 关系视图仅将 29 对数据标识为相似标签候选，不展示为正式 prerequisite。
6. 教材版次未知或不一致时，右侧版本卡必须显式展示，不得默认为最新版。
7. 正式发布门禁未满足时，不提供“正式发布成功”的误导性状态。
