## 验收标准

1. `npm run build` 通过。
2. `npm test` 通过现有回归、课程种子不变量、课标证据与研究快照安全测试。
3. 登录后 `/knowledge-map`、`/knowledge-map/review`、`/knowledge-map/standards` 可访问且不会修改儿童云端数据。
4. 页面明确显示“研究版”，不把未审核数据标记为正式结论。
5. 关系视图仅将 29 对数据标识为相似标签候选，不展示为正式 prerequisite。
6. 教材版次未知或不一致时，右侧版本卡必须显式展示，不得默认为最新版。
7. 修订工作台仅保存本地 draft_only 数据，不直接覆盖种子 JSON 或生成专家审核状态。
8. JSON/HTML 导出物必须标记 `research_only`，HTML 不依赖远程脚本资源。
9. 教育部来源可标记为 `official_source_verified`，但知识点映射在学科审核前必须保持 `candidate_review`。
10. 课标映射不得跨越条款声明的年级范围；缺少可核来源时保持为空，不自动补造。
11. 正式发布门禁未满足时，不提供“正式发布成功”的误导性状态。
