# 课程知识地图集成提案

## 背景

当前“七七伴学”已有家庭学习管理能力；另有一套独立的小学课程知识体系研究原型，已审计统编语文与 PEP 英语种子数据，并建立课程 Schema、修订/审核、研究快照与发布门禁。

本变更将知识体系作为独立研究模块接入七七伴学，但不把未经教研审核的数据视为正式课程结论。

## 目标

1. 在 React 应用中建立 `/knowledge-map` 入口，展示当前知识体系数据状态与发布就绪度。
2. 保留“研究版”和“正式发布”的明确区分。
3. 后续逐步把独立 HTML 中的知识树、图谱、审校与导出能力迁移为 React 可复用模块。
4. 将教材版次、课标映射、教研审核、来源权利作为正式发布硬门禁。

## Non-goals

- 本阶段不导入学生成绩、学习画像或口语录音。
- 不自动生成或伪造专家审核结果。
- 不宣称 459 条种子数据等同于完整中国小学知识库。
- 不在本阶段把全部独立 HTML 代码一次性重写进 React。
- 不放宽现有 CloudBase RLS 或儿童数据保护策略。

## 当前研究数据基线

- 语文：299 条知识大纲条目，1–6 年级。
- 英语：160 条 PEP 知识大纲条目，3–6 年级。
- 教材册次：20。
- 已登记内容问题：7。
- 当前专家审核事件：0。
- 研究版发布门禁：通过。
- 正式版发布门禁：因版次、审核、权利与内容问题被阻断。

## 风险

- 教材版次与当前在用教材可能不一致，必须显示状态而非默认“最新版”。
- 独立研究原型当前使用 JSON/离线 HTML，迁移到 React 后必须保持可追溯与可导出能力。
- 课程内容属于教研高风险数据，UI 测试通过不能替代学科审核。
