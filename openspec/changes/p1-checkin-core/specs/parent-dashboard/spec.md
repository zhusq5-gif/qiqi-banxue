## Purpose

为家长提供简明的完成情况视图，并保障数据主权：全量数据一键导出为开放格式，随时可迁移。

## ADDED Requirements

### Requirement: 今日完成情况

系统 SHALL 在家长视图展示当天各科目完成状态（已完成/未完成）与今日获得星星数。

#### Scenario: 查看今日

- **WHEN** 家长打开家长视图
- **THEN** 看到当天全部科目的完成状态列表与今日新增星星数

### Requirement: 本周统计

系统 SHALL 展示本周（周一起）每日打卡完成率，以直观的日历/条形形式呈现。

#### Scenario: 查看本周

- **WHEN** 家长查看本周统计
- **THEN** 看到周一至今每天的完成科目数/应完成科目数

### Requirement: 全量数据导出

系统 SHALL 提供一键导出功能，将本家庭全部数据（档案、科目、打卡、星星账本、心愿）导出为单个 JSON 文件下载。

#### Scenario: 导出数据

- **WHEN** 家长点击"导出全部数据"
- **THEN** 浏览器下载一个 JSON 文件，内容包含全部五类数据且结构完整可读

#### Scenario: 导出不受数据量影响

- **WHEN** 家庭累计打卡记录超过 1000 条时导出
- **THEN** 导出仍完整包含全部记录，无条数截断
