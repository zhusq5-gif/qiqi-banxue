# 项目蓝图：七七伴学 · 儿童学习管理系统

## 项目定位

为一名 3–12 岁儿童（当前即将 3 岁）构建的个人学习管理系统（LMS），家庭自用、单家庭部署。由家长（chester）与 AI 协作开发，随孩子成长按阶段演进功能。

核心价值：**管理学习过程 + 提供互动内容玩法 + 记录成长数据**，三者合一。

## 技术架构（已确认，全局约定）

| 层 | 选型 | 说明 |
|----|------|------|
| 前端框架 | React 18 + TypeScript + Vite | 一套代码覆盖 iPad（Safari/PWA）、电脑、网页端 |
| UI 样式 | Tailwind CSS | 响应式 + 触控优先（大按钮、大图标） |
| 数据后端 | 腾讯云开发 CloudBase（个人版，环境 `zhusiqi-knowledge-base-dbb4abd2f`） | PostgreSQL 数据库（RLS 行级隔离）+ 邮箱密码登录 + 云函数事务；环境实测 PG 模式（2026-08-27 核实），国内节点延迟 20–40ms |
| 托管 | 腾讯 EdgeOne Pages（免费档） | 静态托管 + GitHub 自动构建，默认域名免备案，国内可访问 |
| 语音 | Web Speech API（浏览器内置） | 字母/单词/古诗朗读，零成本，iPad Safari 原生支持 |
| 内容图形 | 内联 SVG | 图形题、徽章、装饰，无图片版权问题 |

云成本约定：数据层月成本控制在 20 元以内（家庭用量远低于个人版 20 万次调用/月配额）；托管层零成本。

硬性约定（所有变更提案必须遵守）：

1. **数据主权**：任何阶段都提供"导出全部数据"功能（JSON 格式），不绑定单一云厂商。
2. **儿童数据隐私**：云上数据必须开启登录保护；不接入第三方统计分析 SDK。云厂商限定中国国内（腾讯云），数据存储于境内节点。
3. **年龄适配**：界面区分「低龄模式」（3–6 岁：大图标、语音引导、即时奖励）与「学龄模式」（6–12 岁：任务列表、进度统计），同一账号可切换。
4. **离线容忍**：内容数据（题库、卡片）打包进应用，不依赖运行时外部 API。

## 内容数据来源策略

内容模块的题库/卡片数据**由 AI 直接生成**，以 JSON 文件纳入版本库（`src/content/`），离线可用、零成本、无版权风险。不依赖外部教育平台 API。发音用 Web Speech API，图形用 SVG。

例外：后续「识字模块」可引入 makemeahanzi 开源汉字笔顺数据集（公有领域授权），届时单独提案。

## 能力路线图（每阶段 = 一个变更提案）

### P1 · 打卡核心（MVP，上线即可日常使用）

- 儿童档案（头像、昵称、生日）
- 每日学习打卡（自定义科目/活动）
- 星星奖励与兑换（星星 → 礼品/特权）
- 家长视图（今日完成情况、本周统计）
- CloudBase 邮箱登录（家长账号）+ 数据导出

### P2 · 计划与内容卡片

- 学习计划与课程表（周视图）
- **字母乐园**：26 个英文字母卡片，点击发音（Web Speech API），大小写配对游戏
- **古诗花园**：8 首经典幼儿古诗，带拼音标注，点击朗读
- （预留）识字卡：makemeahanzi 笔顺数据

### P3 · 练习与测验引擎

- 通用练习引擎：随机出题、选项作答、自动判分、错题记录
- **数字王国**：0–20 数字认知、10 以内加减法随机出题、数数小游戏
- **逻辑挑战**：找规律、图形配对、排序题，每题 3–4 个选项

### P4 · 成长平台

- **闯关冒险**：综合各模块题库闯关，星星奖励，成就徽章墙
- 学习报告（周/月维度，习惯养成曲线）
- 多子女支持、习惯追踪

## 交付节奏约定

- 每个阶段先出变更提案（proposal/specs/tasks），经 chester 确认后再实现。
- P1 上线后实际使用 1–2 个月，再根据真实使用情况调整 P2–P4 优先级。
- 孩子的实际使用习惯优先于预设设计，允许路线图调整。

## 变更制品规则

- proposal 必须包含「Non-goals」章节，防止范围蔓延。
- specs 使用 Requirement/Scenario 格式，SHALL 关键字保留英文。
- tasks 按可独立验证的粒度拆分，每项完成后可勾选。
